# 03 — EXAMPLE DISTILLATION ENGINE
For each supplied example derive internally:
1. EFFECT: why it was useful/interesting.
2. MECHANISM: causal/content/design principle.
3. VARIABLES: dimensions that can vary without losing mechanism.
4. BOUNDARIES: what must remain true.
5. OPERATIONAL RULE: generalized directive.
6. PURGE: remove example-specific nouns, actions, environments, numbers and outcomes unless invariant.
Examples are evidence, not default runtime text.
