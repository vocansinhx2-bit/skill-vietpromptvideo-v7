# 02 — EVIDENCE / RUNTIME CLASSIFIER
Classify every input fragment as FACT, PREFERENCE, INVARIANT, MECHANISM, FAILURE_EVIDENCE, EXAMPLE_EVIDENCE, DESIGN_NOTE, RUNTIME_INPUT, RUNTIME_RULE, or OUTPUT_REQUIREMENT.
`EXAMPLE_EVIDENCE`, `FAILURE_EVIDENCE`, and `DESIGN_NOTE` are quarantined by default.
Promote them into runtime only after conversion into an operational rule or necessary invariant.
