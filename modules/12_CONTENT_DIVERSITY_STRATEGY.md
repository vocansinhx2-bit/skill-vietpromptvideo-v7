# 12 — CONTENT DIVERSITY & STRATEGY
For repeated content, separate invariants from variation dimensions.

## 12.1 Invariants vs variables
| Layer | Keep fixed across a series | Vary per episode |
|---|---|---|
| Identity | character look, wardrobe lock, brand assets | expression, pose, activity |
| World | location family, lighting logic, color script | time of day, weather, sub-location |
| Format | aspect ratio, duration band, ending type | hook type, beat structure |
| Voice | narrator tone, sound motif | line content, music variation |

## 12.2 Variation dimensions
Audit convergence by: hook type, problem, progression, interaction mechanism, camera pattern, lens family, payoff type, ending type, emotional curve, environment, subject class, sound design.
A series batch passes when no single dimension repeats in more than half of the episodes, and no two episodes share more than 4 dimensions.

## 12.3 Anti-skeleton rule
Avoid "same skeleton + renamed subject". Two episodes with the same hook, beats and payoff but a different object count as one idea.

## 12.4 Series rhythm
- Rotate hook types from module 49.2 across consecutive episodes.
- Rotate emotional curves from module 49.3.
- Keep one recurring signature element (sound motif, opening framing or closing gesture) so the series stays recognizable.

## 12.5 Batch workflow
1. Write the invariant sheet (12.1).
2. Generate 2–3x the needed ideas.
3. Tag each idea on the 12.2 dimensions.
4. Remove convergent pairs, keep the strongest.
5. Order the batch so adjacent episodes differ on hook and curve.

## 12.6 Error codes
| Code | Signal |
|---|---|
| `SERIES_CONVERGENT` | 12.2 threshold exceeded |
| `SKELETON_CLONE` | same structure, renamed subject |
| `INVARIANT_DRIFT` | a fixed layer changed between episodes |

Use story grammar only when it improves causality and payoff (module 20).
