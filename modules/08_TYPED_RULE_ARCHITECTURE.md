# 08 — TYPED RULE ARCHITECTURE
Rule types: HARD_CONSTRAINT, INVARIANT, CONDITIONAL_RULE, ALLOWED_DELTA, EXCLUSION, SOFT_PREFERENCE, QUALITY_HEURISTIC, FALLBACK, PRECEDENCE.
`EXAMPLE` is NOT a runtime rule type. Examples live in evidence/test layers.
Prefer positive operational directives over explanatory prose or long negative lists.
