# MASTER PROMPT PURITY STANDARD
A Master Prompt is pure when a downstream AI can consume it without needing the design history that produced it.
Forbidden by default inside runtime core:
- research narration;
- benchmark results;
- creator-facing explanations;
- historical examples used only for training;
- source/provenance narration;
- scoring commentary;
- one-off patches tied to a prior failure.
Permitted:
- rules, inputs, invariants, decision logic, output schema, conditional fallbacks, necessary definitions.
