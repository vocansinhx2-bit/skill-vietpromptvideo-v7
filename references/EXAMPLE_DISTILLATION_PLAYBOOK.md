# EXAMPLE DISTILLATION PLAYBOOK
Use examples to infer reusable mechanics.
Bad compile: preserve the example nouns/actions as a menu.
Good compile: preserve effect/mechanism and expose variable dimensions.
Internal template:
- Source example
- Useful effect
- Mechanism
- Variable dimensions
- Boundaries/invariants
- General rule
- Contamination tokens to purge
Only the general rule belongs in runtime by default.
