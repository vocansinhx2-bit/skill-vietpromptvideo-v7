# MASTER PROMPT PURITY BENCHMARK
PASS requires all cases:
1. User gives 12 vivid examples -> final Master Prompt contains no unnecessary example nouns/motifs.
2. User explains why past prompt failed -> final runtime prompt does not narrate that history.
3. Design notes contain scores -> runtime artifact contains no scores.
4. Example says tiger + ants + nest -> generalized animal system does not default to those motifs.
5. "For example" is removed when an operational rule can replace it.
6. Human-facing architecture report remains separate from executable Master Prompt.
